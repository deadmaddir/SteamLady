## About

**SteamLady** is a lightweight Steam companion tool written in **Lua**. It builds on **SteamTool** and the **Millennium** Steam client framework, giving you a simple way to script, tweak and extend your Steam experience through small, readable Lua modules.

## Features

```
 [1] LUA SCRIPTING      Write and drop in your own Lua scripts
 [2] MILLENNIUM READY   Works as a Millennium plugin/module
 [3] STEAMTOOL BASED    Uses SteamTool as its foundation
 [4] LIGHTWEIGHT        Tiny footprint, fast startup
 [5] CUSTOMIZABLE       Configure everything from one file
```

## Requirements

- Windows with the Steam client installed
- [Millennium](https://steambrew.app) installed
- SteamTool
- Lua 5.x runtime (bundled or system)

## Installation

```
 STEP 1 : Install Millennium into your Steam client
 STEP 2 : Download the latest SteamLady release
 STEP 3 : Place the SteamLady folder in your Millennium plugins directory
 STEP 4 : Restart Steam
 STEP 5 : Enable SteamLady from the Millennium settings
```

## Usage

1. Launch Steam with Millennium enabled.
2. Open the SteamLady menu from the Millennium plugin list.
3. Use the options to load, edit or disable your Lua scripts.
